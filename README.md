# Open Backrooms

**Noclip into the Backrooms, right in your browser.** Open Backrooms is a free, open-source, hyper-real Backrooms horror game. It runs on most PCs and Macs, with no download, no account and no payments.

**Play:** https://awn3x.github.io/Open-Backrooms/ (once Pages is enabled; see below)

## Features

- **Three levels:** Level 0 *The Lobby*, Level 1 *Habitable Zone*, Level 2 *Pipe Dreams*, then an ending. Each is infinite and procedurally generated with the same attention to detail.
- **The Base:** a lit safe zone at spawn with a supply kiosk, lockers and a bulletin board.
- **Backrooms Coins (BC):** earned only by playing (exploring, surviving, finding Almond Water, escaping). There is no real money anywhere in the game.
- **Multiplayer:**
  - Public worlds with region-based matchmaking (NA/SA/EU/AF/AS/OC, 8 players per world, automatic overflow).
  - Custom rooms with an optional password and a shareable invite link.
  - 3D proximity voice with wall occlusion and reverb.
  - Text chat with a toggleable profanity filter.
- **AI mode:** play offline with two AI companions. There's no chat, board or voice, but you still earn coins.
- **Entities:**
  - Crawlers hunt by sound.
  - The Watcher moves only when unobserved.
  - Smilers hate light.
  - Mimics copy your friends.
  - Pipe-dwellers live in Level 2.
- **Feel:** gait-driven head bob and sway, breathing, handheld tremor, landing and bump springs, stamina, crouch, and real camera motion blur. The camcorder/VHS pass is subtle and adjustable.
- **Sound:**
  - Synthesised footsteps on four surfaces.
  - Positional 120 Hz fluorescent hum.
  - Sparking outlets.
  - Breathing and heartbeat layers.
  - HRTF 3D audio with wall occlusion and per-level convolution reverb.
- **Runs almost anywhere:** automatic quality presets, dynamic resolution, and a baked light field that lets hundreds of fixtures light the scene cheaply.

## Controls

WASD move · Shift sprint · C crouch · Space jump · F flashlight · E interact · Q drink Almond Water · R swap battery · T chat · V push-to-talk · Tab players / pause · Esc pause. Gamepads are supported.

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173/play/
npm test           # world-gen determinism / connectivity tests
npm run build      # static site in dist/
```

## Deploy (free)

The build is a static site with relative URLs, so the same `dist/` works on GitHub Pages under `/Open-Backrooms/` and on Vercel at the root. Multiplayer is peer-to-peer (WebRTC, signalled over public Nostr relays through [Trystero](https://github.com/dmotz/trystero)), so there's no server to host or pay for.

**GitHub Pages**
1. Merge to `main`.
2. In the repo, go to **Settings → Pages → Build and deployment → Source** and choose **GitHub Actions**.
3. The `Deploy to GitHub Pages` workflow builds and publishes on every push to `main`. (Or run it from the Actions tab.)

> **Site looks like plain unstyled text?** Pages is serving the raw source. Set **Settings → Pages → Source** to **GitHub Actions** (not "Deploy from a branch") and re-run the workflow.

**Vercel**
1. Go to https://vercel.com/new and import the repository (the free Hobby plan is fine).
2. The framework is detected from `vercel.json` (Vite, `npm run build`, output `dist`). Click **Deploy**.

## How the assets are made

Everything is generated by scripts in `tools/`:

- `tools/textures/`: tileable PBR texture generators in numpy (wallpaper, carpet, ceiling tile atlas, lens, decals, concrete, pipe metal, block, plate). Each writes albedo, normal and ORM maps in two resolution tiers.
- `tools/blender/`: Blender (`bpy` 4.5) scripts that model the outlets (duplex, two-prong, GFCI, broken), switch plates, troffers, vents, exits, hub furniture and props. They also build and rig the creatures and the player avatar from skin-modifier skeletons with keyframed clips, then export glTF.
- `tools/audio/`: DSP sound design (numpy/scipy) exported to Ogg Vorbis and AAC.

```bash
python -m venv .venv && . .venv/bin/activate
pip install bpy==4.5.4 numpy scipy soundfile imageio-ffmpeg pillow
python tools/textures/gen_l0.py && python tools/textures/gen_l12.py
python tools/blender/build_all.py
python tools/audio/build_audio.py
```
